## 🚀 How to Run Locally

You can run this portfolio locally in any browser without needing to install Node.js or any build tools:

1. **Directly in Browser**:
   - Double-click `index.html` to open it in your browser (Chrome, Edge, Firefox, Safari).

2. **Using VS Code Live Server**:
   - Open the `roshdy-portfolio` folder in VS Code.
   - Right-click `index.html` and click **"Open with Live Server"**.

3. **Using Python Simple HTTP Server**:
   ```bash
   cd C:\Users\roshd\OneDrive\Desktop\roshdy-portfolio
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser.

## ✏️ How to Customize Your Personal Links

Open `index.html` and look for the `<!-- EDITABLE LINK -->` markers in the **Contact Section**:

- **Email**: Update `mailto:your.email@example.com` and the text inside `<a id="emailLink">`
- **GitHub**: Replace `https://github.com/yourusername` with your real profile link
- **LinkedIn**: Replace `https://linkedin.com/in/yourprofile` with your real profile link
- **Instagram**: Replace `https://instagram.com/yourusername` with your real profile link
